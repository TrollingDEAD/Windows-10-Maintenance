# Code of Conduct

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, background, identity, experience level, or opinions.

## Expected behavior

- Be respectful and constructive.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and its users.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks
- Trolling or deliberately derailing discussions
- Publishing others' private information without permission

## Enforcement

Maintainers may edit or remove comments, commits, issues and other contributions that violate this code, and may temporarily or permanently ban contributors for behavior they deem inappropriate. Report concerns privately through GitHub's **Report content** feature or by contacting a maintainer via their GitHub profile.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
