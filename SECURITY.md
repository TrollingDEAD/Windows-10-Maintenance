# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

This script runs with administrator rights, so security issues matter. Please **do not** open a public issue.

Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include what you found, the steps to reproduce it, and the impact you expect. You can expect an initial response within about 7 days.

## Verifying what you run

The tool is a single, readable script. Read it before running it as administrator, and download it only from this repository's releases or default branch.
